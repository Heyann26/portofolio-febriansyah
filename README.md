## ✨ Fitur Utama

1. **Cinematic Opening Screen (Api & Karakter Membara):**

   - Simulasi partikel api (*fiery embers & sparks*) dinamis pada kanvas pembuka.
   - Lambang karakter api (*dancing flame crest*) dengan efek cahaya berdenyut.
   - Indikator pemuatan progresif futuristik dan tombol pintas *Skip*.

2. **Cinematic 3D Depth Cutout Hero (Seperti di TikTok):**
   - Tipografi nama raksasa di belakang subjek (`FEBRIANSYAH`).
   - Foto subjek berjas (*cutout*) di lapisan depan dengan kedalaman realistis.
   - Efek stroke teks di lapisan terdepan yang membungkus subjek secara 3D.
   - Efek *mouse parallax tilt* yang bergerak mulus merespons kursor mouse.
   - Partikel debu/ember merah dan konstelasi melayang dinamis di background seluruh halaman.

## 🚀 Cara Menjalankan

### Cara 1: Buka Langsung di Browser (Paling Mudah)
Cukup klik ganda (double-click) file **`index.html`** di Windows Explorer, website langsung terbuka dan berjalan sempurna di Google Chrome, Edge, Firefox, dll.

### Cara 2: Menjalankan Local Server via Terminal
Jalankan perintah berikut di terminal:
```bash
npm start
```
Lalu buka browser di `http://localhost:3000`.
